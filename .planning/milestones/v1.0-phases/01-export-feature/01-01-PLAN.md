<task type="auto">
  <name>Task 3: Create API route (app/api/export/[id]/route.ts)</name>
  <files>app/api/export/[id]/route.ts</files>
  <action>
    Create the directory `app/api/export/[id]/` and `route.ts` inside it.

    ```typescript
    import { NextRequest, NextResponse } from "next/server";
    import { getChangeRequest } from "@/lib/db";
    import { buildCsvContent, buildExportFilename, CONTENT_TYPE_CSV, CONTENT_TYPE_PDF, type ExportFormat } from "@/lib/export";
    import { buildPdfBuffer } from "@/lib/export-pdf";
    ```

    **GET handler** (async, takes `request: NextRequest` and `{ params }: { params: Promise<{ id: string }> }`):

    1. Extract `id` from `params` (await it — Next.js 16 pattern per existing routes)
    2. Extract `format` from `request.nextUrl.searchParams`
    3. Validate format is `"csv"` or `"pdf"` — if invalid, return 400 JSON: `{ error: "Ongeldig exportformaat. Gebruik format=csv of format=pdf." }`
    4. Call `getChangeRequest(id)` — per D-03 (export current change request only)
    5. If null/undefined, return 404 JSON: `{ error: "Change request niet gevonden." }`
    6. Build filename via `buildExportFilename(request, format === 'csv' ? 'csv' : 'pdf')`
    7. Based on format:
       - `csv`: Build content via `buildCsvContent(request)`, set Content-Type to `CONTENT_TYPE_CSV`, Content-Disposition to `attachment; filename="${filename}"`
       - `pdf`: Build buffer via `await buildPdfBuffer(request)`, set Content-Type to `CONTENT_TYPE_PDF`, Content-Disposition to `attachment; filename="${filename}"`
    8. Return `new NextResponse(content, { status: 200, headers: { ... } })`
    9. Wrap in try/catch — on error return 500 JSON: `{ error: "Export mislukt." }`

    Set `export const dynamic = "force-dynamic";` (no caching for downloads per D-09 immediate download).

    Per D-09: The route returns the file directly as an attachment — no intermediate page or preview.

    Content-Disposition header format: `attachment; filename="${filename}"`. The filename is URL-encoded or ASCII-safe (for CSV it's already ASCII with hyphens/numbers, for PDF similarly).

    Import pattern matches existing routes (e.g., `app/api/commits/route.ts`).
  </action>
