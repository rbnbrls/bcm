  <files>components/export-button.tsx</files>
  <action>
    Create `components/export-button.tsx` as a `"use client"` component.

    **Component name:** `ExportButton`

    **Props:**
    - `changeRequestId: string` — the UUID of the current change request

    **Imports:**
    - `"use client"` directive at top
    - `{ useState, useRef, useCallback }` from "react"

    **State:**
    - `downloading: boolean` — tracks whether a download is in progress (per D-10)
    - `open: boolean` — tracks whether the dropdown is visible

    **Ref:**
    - `dropdownRef: RefObject<HTMLDivElement>` — for click-outside detection

    **Render structure (per D-07 split button / button group):**

    ```
    <div className="export-split">
      <button className="export-split__main" onClick={handleDownloadCSV} disabled={downloading}>
        {downloading ? "Exporteren…" : "Exporteer request"}
      </button>
      <button className="export-split__arrow" onClick={toggleDropdown} disabled={downloading} aria-label="Exportformaat kiezen">
        <svg chevron-down icon />  (or a simple ▼ character)
      </button>
      {open && (
        <div className="export-split__dropdown" ref={dropdownRef}>
          <button onClick={handleDownloadCSV}>CSV downloaden</button>
          <button onClick={handleDownloadPDF}>PDF downloaden</button>
        </div>
      )}
    </div>
    ```

    **Behavior:**

    - Per D-10: When `downloading` is true, the main button text shows "Exporteren…" and both buttons are disabled
    - Main button click triggers CSV download (most common format)
    - Arrow button toggles the dropdown
    - Dropdown has two options: "CSV downloaden" and "PDF downloaden"
    - Click-outside on the dropdown closes it (use `useEffect` with `mousedown` listener on `document`)
    - Per D-09: Download is immediate — no intermediate page. Use a hidden `<a>` element with the download URL:
      ```ts
      const triggerDownload = useCallback((format: 'csv' | 'pdf') => {
        setDownloading(true);
        const a = document.createElement('a');
        a.href = `/api/export/${changeRequestId}?format=${format}`;
        a.download = ''; // let server-set Content-Disposition name it
        document.body.appendChild(a);
        a.click();
        document.body.removeChild(a);
        // Reset loading state after a short delay
        setTimeout(() => setDownloading(false), 1500);
      }, [changeRequestId]);
      ```

    - Per D-07: The split button is a `<div>` with two `<button>` elements styled as one control

    **Important:** Do NOT put fenced code blocks in the action text body when providing directive prose — the code snippets above are illustrative. The executor will write actual implementation code, not copy action text literally.

    Follow the existing `"use client"` component pattern from `components/feedback-button.tsx` (useState, event handlers, etc.). Do NOT add server-side logic to this file.
