    Add Playwright E2E tests as a **separate job** named `e2e-test` that runs in parallel with `test`:
    - Use `runs-on: ubuntu-latest`
    - Strategy matrix with `node-version: [20]`
    - Steps (in order):
      1. `actions/checkout@v4`
      2. `actions/setup-node@v4` with `node-version` and `cache: 'npm'`
      3. `- run: npm ci`
      4. `- run: npx playwright install --with-deps chromium` — install Chromium browser binary with system dependencies
      5. `- run: npm run test:e2e` — run Playwright tests (the webServer config auto-starts the Next.js dev server)
      6. `- uses: actions/upload-artifact@v4` on failure (`if: failure()`):
         - name: `playwright-report-${{ matrix.node-version }}`
         - path: `playwright-report/` and `test-results/`
    - Set `concurrency` group: the existing `concurrency` at workflow level already handles cancellation. Do not duplicate.
    - Use `timeout-minutes: 15` for the job to prevent runaway test execution.

    Use Edit (scoped) to:
    1. Read the existing ci.yml to find the exact insertion point after the existing `test` job definition.
    2. Append the new `e2e-test` job after the closing of the `test` job.
    3. Do NOT rewrite the entire file — use a targeted edit that inserts the new job after the existing test job's last line.
