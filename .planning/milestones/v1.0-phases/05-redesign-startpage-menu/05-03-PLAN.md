    Add a new test block after the axe-core audit tests (after line 26):
    ```typescript
    test.describe("Dashboard focus styles", () => {
      test("category cards have visible focus-visible outline", async ({ page: p }) => {
        await p.goto("/");
        await p.waitForLoadState("networkidle");
        const card = p.locator(".category-card").first();
        await card.focus();
        // Use tab to focus the first card — category cards don't receive focus natively,
        // but the first action link (primary-link) should
        await p.keyboard.press("Tab");
        await expect(card.locator(".category-card-action.primary-link")).toBeFocused();
      });
    });
    ```

    Note: Category cards themselves are `<article>` elements and not tabbable. The focus-visible outline is on the card element for mouse/keyboard interaction, and action links are focusable via Tab. The test verifies the first action link receives focus.
