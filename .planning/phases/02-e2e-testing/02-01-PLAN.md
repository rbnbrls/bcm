<task type="auto">
  <name>Task 1: Install Playwright, create config, update package.json</name>
  <files>package.json, playwright.config.ts</files>
  <action>
    1. Install Playwright: `npm install -D @playwright/test` (no `--save-exact`, let npm resolve). Do NOT run `npx playwright install` yet — that's the user_setup step (browser binaries).
    2. Create `playwright.config.ts` at project root with:
       - `testDir: './tests/e2e'`
       - `fullyParallel: true`
       - `retries: 0` (local) / `retries: 2` (CI via `retries: process.env.CI ? 2 : 0`)
       - `workers: process.env.CI ? 2 : undefined`
       - `reporter: [['html', {outputFolder: 'playwright-report'}], ['list']]`
       - `use: { baseURL: 'http://localhost:3000', trace: 'on-first-retry' }`
       - `webServer` block:
         - `command: 'npm run dev'` (uses existing dev script which runs `next dev`)
         - `url: 'http://localhost:3000'`
         - `reuseExistingServer: !process.env.CI` (reuse local dev server when not in CI)
         - `cwd: '.'`
       - `projects` with one project: `{ name: 'chromium', use: { ...devices['Desktop Chrome'] } }`
       - Import `defineConfig` and `devices` from `@playwright/test`.
       - Per D-02: Use standard `@playwright/test` integration (no next/experimental/test — use the standard @playwright/test package which works with any Next.js project via webServer config).
    3. Update `package.json` scripts section — add after `"test:watch"`:
       ```json
       "test:e2e": "playwright test",
       "test:e2e:ui": "playwright test --ui"
       ```
       Use Edit (scoped) to append these two lines to the `"scripts"` object. Do NOT rewrite the entire file.
    4. Add `playwright-report/` to `.gitignore` (under `*.log` line, add: `/playwright-report/` and `/test-results/`).
    5. Add `test-results/` path to the existing `path` block in `.github/workflows/ci.yml` (the CI artifact upload step already uploads `test-results/` — ensure the path matches Playwright's default output).
  </action>
  <verify>

        console.log('scripts OK');
      "
    </automated>
  </verify>
  <done>
    - `npm run test:e2e -- --help` exits with usage text (playwright test runner is installed)
    - `playwright.config.ts` exists with webServer config pointing to Next.js dev server

    - `.gitignore` excludes `playwright-report/` and `test-results/`

<task type="auto">
  <name>Task 2: Create E2E test helpers and fixture data for tests</name>
  <files>tests/e2e/helpers.ts, tests/e2e/global-setup.ts</files>
  <action>
    Do NOT create any spec (.spec.ts) test files in this task — only create helper/utility files.

    1. Create `tests/e2e/helpers.ts` with:
       - Import `{ Page, expect }` from `@playwright/test`.
       - Export `DEMO_CLIENT_NAME = 'Pensioenfonds Horizon'` — the default client used in fixture data.
       - Export `DEMO_PORTFOLIO_NAME = 'Rendementsportefeuille'` — the first portfolio of the demo client.
       - Export `async function navigateToBenchmarkSwitch(page: Page)` — navigate to `/changes/new` via the homepage CTA:
         - Call `page.goto('/')`
         - Click `a[href="/changes/new"]` (the "Start benchmarkwissel" button)
         - Wait for URL to contain `/changes/new`
       - Export `async function navigateToCatalog(page: Page)`:
         - Call `page.goto('/')`
         - Click `a[href="/benchmarks"]` ("Catalogus bekijken")
         - Wait for URL to contain `/benchmarks`
       - Export `async function navigateToNewBenchmarkRequest(page: Page)`:
         - Call `page.goto('/')`
         - Click `a[href="/benchmark-aanvraag"]` ("Aanvragen")
         - Wait for URL to contain `/benchmark-aanvraag`
       - Export `async function selectClient(page: Page, clientName: string)`:
         - Find the first `select` element (the "Klant" dropdown) and select the option with text matching `clientName`.
       - Export `async function selectPortfolio(page: Page, portfolioName: string)`:
         - Find the checkbox in the portfolio card with `<b>${portfolioName}</b>` and check it.
       - Export `async function setSOLLBenchmark(page: Page, portfolioId: string, benchmarkCode: string)`:
         - The SOLL select is inside the portfolio card. Use the portfolio card context to find the second select (SOLL) and select by label or value.
         - Since DOM structure: `.portfolio-card` contains both IST and SOLL selects. SOLL is the second select inside `.benchmark.soll`.
       - Export `async function fillFormFields(page: Page, fields: Record<string, string>)`:
         - For each [name, value] pair, fill `input[name="${name}"]` or `textarea[name="${name}"]`.
       - Export `async function submitForm(page: Page)`:
         - Click `button[type="submit"]`.
         - Wait for navigation or for a success indicator (`.change-request-detail`, `[role="alert"]`, or URL change).
       - Export fixture data constants matching `lib/fixtures.ts`:
         - `VALID_BENCHMARK_1_ID = '9fb65c5a-5ccf-4374-a264-9b03c9ac3bd1'` (MSCI-World-NR)
         - `VALID_BENCHMARK_2_ID = 'b9ec8da5-5d7a-4ee0-a23e-9746ded5b43d'` (MSCI-ACWI-NR)
         - `VALID_CLIENT_ID = '9f9280fc-9572-49d1-b81c-2a039652bc93'`

    2. Create `tests/e2e/global-setup.ts` (auto-loading via playwright.config.ts `globalSetup`):

       - Reference this in `playwright.config.ts` by adding `globalSetup: './tests/e2e/global-setup.ts'`.

    3. Update `playwright.config.ts` to add `globalSetup: './tests/e2e/global-setup.ts'` to the config object.
