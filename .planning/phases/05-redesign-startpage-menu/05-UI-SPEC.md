## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline element spacing |
| sm | 8px | Compact element spacing, skeleton border-radius |
| md | 16px | Default element spacing, card padding (category cards) |
| lg | 24px | Section padding, card padding, page shell padding (mobile) |
| xl | 32px | Layout gaps, section-to-section spacing |
| 2xl | 48px | Major section breaks, skeleton padding |
| 3xl | 64px | Page-level top padding (home-shell) |

Exceptions:
- **Existing utility values preserved** (6, 10, 12, 14, 18, 20, 28px) — these appear in existing component CSS (e.g. `10px 14px` on buttons/inputs, `12px 20px` on cards, `28px` in topbar padding formula). Do NOT refactor these to 4px multiples.
- **New category card layout** MUST use strict multiples of 4.
- Touch targets ≥44px (WCAG 2.5.8) at 768px breakpoint, per existing NFR-06.

**Source:** CONTEXT.md §code_context, globals.css responsive rules, user confirmation

## Color

| Role | Variable | Value | Usage |
|------|----------|-------|-------|
| Dominant (60%) | `--canvas` | #eef1ed | Page background, main surfaces |
| Secondary (30%) | `--panel` | #f6f8f5 | Card backgrounds, topbar, table headers, secondary surfaces |
| Accent (10%) | `--accent` | #0f6d55 | Primary buttons, navigation links (hover), category card borders (hover), focus-visible outlines, status badges, brand icon accent |
| Accent deep | `--accent-deep` | #0a513f | Button hover, body text on white surfaces (AA contrast), emphasized accent states |
| Accent tint | `--mint` | #dff4e9 | Background fills on accent elements, selected states, success banners |
| Text | `--ink` | #14231e | Primary body text |
| Text muted | `--muted` | #5d6864 | Secondary text, labels, placeholders |
| Border | `--line` | #d9dfdb | Borders, dividers, card outlines |
| Destructive | `--danger` | #a44032 | Destructive action buttons, error text |
| Danger bg | `--danger-bg` | #fff0ed | Error state backgrounds, form error boxes |
| Code | `--code` | #15221e | Monospace text, code blocks |

Accent (`--accent`) reserved for:
- Primary buttons (`.button`, `.button-primary`)
- Navigation links on hover (`.topbar nav a:hover`)
- Category card border on hover
- `:focus-visible` outlines
- Status badges and pills (active/success variants)
- Brand mark icon in topbar (`.brand span`)
- Feedback trigger button
- CTA links
- Sort header hover state

**Do NOT** use accent for: body text, default backgrounds, disabled elements, muted labels, borders on non-interactive elements.

**Source:** globals.css `:root` block, existing component patterns

## UI Considerations

> State coverage for the new dashboard and redesigned menu.

Applicable state considerations resolved: **5 covered, 2 backstop, 0 unresolved**

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Category card grid | ✅ covered | Render empty state heading + body from Copywriting Contract |
| error | Dashboard data load | ✅ covered | Render error state copy + optional retry button (reuse existing `.button` pattern) |
| loading | Dashboard data fetch | ✅ covered | Reuse existing `.skeleton-card`, `.skeleton-heading`, `.skeleton-text` classes from globals.css |
| populated | Category card grid | ✅ covered | Render category cards with icon, title, description, and action links |
| active | Navigation menu items | ✅ covered | Existing `color: var(--accent)` hover state; add `.topbar nav a[aria-current="page"]` for active page indicator |
| overflow | Many tools within a category | 🧪 backstop | Card grid wraps naturally via `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`. Backstop: visual test with 8+ tool links in one category. |
| long-text | Category descriptions or tool names | 🧪 backstop | Truncate tool link text with `text-overflow: ellipsis`. Backstop: visual test with a 150-character tool name. |
| zero-one-many | Category count | ✅ covered | 0 → empty state; 1 → single category renders as one card (edge case, acceptable); 5 → normal populated state |

## Interaction Contract

### Category Card Interaction
| Trigger | Behavior |
|---------|----------|
| Card hover | Border transitions to `--accent` (from `--line`). Background shifts to `#fff` (from `#fbfcfa`). Subtle shadow (existing `box-shadow: 0 2px 12px rgba(15,109,85,.08)` from `.change-type-card`). Cursor → pointer. |
| Card click | Navigate to the first/second action link within the card? Or expand to show tools? **Decision needed at plan time.** |
| Focus-visible | Existing `2px solid var(--accent-deep)` outline with 2px offset. |
| Action link click | Navigates directly to the target page. Standard link behavior. |

### Navigation (topbar) Changes
| Current | New |
|---------|-----|
| Changes | → **Wijzigingen** (unchanged) |
| Nieuwe change | → Remove from topbar; move to "Benchmark wijzigingen" category card as action |
| Benchmark catalogus | → Remove from topbar; move to "Benchmark wijzigingen" category card as action |
| Beheer | → Keep as **Beheer** |
| Wijzigingshistorie | → Remove from topbar; move under "Rapportages & analyses" or "Monitoren & verwerken" |
| Rapportages | → Keep as **Rapportages** |
| — | → No new top-level nav items |

**New topbar nav order:** Dashboard (home) | Wijzigingen | Rapportages | Beheer

### Responsive Behavior
| Breakpoint | Layout Changes |
|------------|----------------|
| >768px | Full 5-category grid: 2 columns (3 + 2) or 3 columns. Category cards in horizontal layout with icon, title, description, action links. |
| 768px | Category grid collapses to single column. Topbar wraps to multi-line. Category cards stack vertically. |
| 600px | Compact spacing. Topbar font-size 12px. Category card padding reduced to 16px. |

**Source:** Existing responsive patterns from globals.css (768px and 600px media queries), NFR-06
