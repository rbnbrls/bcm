# Workflow Studio Operating Handbook

Deze map is de operationele handleiding voor change managers, beheerders,
support en proceseigenaren. Architectuurcontracten staan in
`documentation/architecture`; deze documenten beschrijven hoe een pilotgroep de
Workflow Studio zonder ontwikkelaar gebruikt en beheert.

## Releasegebruik

Voor G4 moet de pilotgroep aantonen dat zij een proces kan ontwerpen,
simuleren, publiceren, starten, uitvoeren, herstellen en beheren met deze
handleidingenset. De geautomatiseerde readiness-check bewaakt dat de verplichte
documenten en kernthema's aanwezig blijven.
