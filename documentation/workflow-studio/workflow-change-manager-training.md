# Workflow Studio Change Manager Training

Deze training laat een pilotgroep aantonen dat zij zonder ontwikkelaar een
proces kan ontwerpen, testen, publiceren en uitvoeren.

## Leerdoelen

- Een template kiezen en naar een draft omzetten.
- Scope, metadata, cost model en catalog description invullen.
- Blocks toevoegen, verbinden en met keyboard/outline/minimap bewerken.
- Variabelen, lookups, approvals en change_request mappings configureren.
- Simulatie uitvoeren en validatie oplossen.
- Review aanvragen, publiceren, starten, taak uitvoeren en goedkeuren.
- Dashboard, runbook en incidentprocedure gebruiken bij afwijkingen.

## Oefening

1. Maak een benchmarkwissel-draft uit `benchmark_switch.v1`.
2. Voeg een risicogoedkeuringsfragment toe.
3. Configureer starter, uitvoerder en approver als gescheiden rollen.
4. Simuleer happy path en reject path.
5. Dien review in en laat een tweede deelnemer goedkeuren.
6. Publiceer de workflow.
7. Koppel het actieve change type aan de gepubliceerde workflowversie.
8. Start een instance via de change catalogus.
9. Rond de taak en approval af.
10. Toon audit trail, runtime detail en dashboardstatus.

## Slagingscriteria

De deelnemer slaagt wanneer de instance zonder ontwikkelaar tot een gecontroleerd
eindresultaat komt, alle governance issues verklaard of opgelost zijn en de
deelnemer het juiste runbookpad voor een foutscenario kan aanwijzen.
